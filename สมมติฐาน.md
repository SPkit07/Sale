## 🔍 ANOMALY DETECTION & HYPOTHESIS PIPELINE (CAVEMAN MODE)

### 1. MISSING IMPORT (บิลรับเข้าหาย / ลืมคีย์)
* **Hypothesis:** Sales continue normally, but staff forgot to key in the import bill.
* **Trigger:** Import gap exceeds $2\times$ average import interval while sales persist.
* **Action:** If stock is negative, execute **Reverse Calculation** to estimate missing master/inner packs using historical intake patterns.

### 2. GHOST STOCK (คีย์บิลเกิน / สต็อกบวม)
* **Hypothesis:** Over-entry, duplicate bills, or phantom inventory.
* **Trigger:** Zero sales for $>2\times$ normal cycle, then an import appears, followed by sudden normal sales resumption.
* **Action:** Flag the prior intake as "Ghost Stock" (if it were real, it would have sold sooner).

### 3. DEAD STOCK (สต็อกค้างนานไร้ความเคลื่อนไหว)
* **Hypothesis:** Lost, damaged, or mis-keyed phantom items.
* **Trigger:** No sales for $>2\times$ normal cycle and no new imports, yet system shows leftover inventory.

### 4. STOCK OUT (สต็อกหมด / ติดลบ)
* **Hypothesis:** Selling items when physical inventory is already depleted (consequence of missing import bills).
* **Trigger:** Negative or zero running balance while sales (Export) occur on the same day.

### 5. IMPORT OUTLIERS (ยอดรับเข้าพุ่งสูง) - 4 SUB-HYPOTHESES:
* **5.1 Barcode Swap (สลับบาร์):** Divide spike by master/inner pack size. If normalized value passes **Robust Z-Score**, it's a barcode mismatch.
* **5.2 Double Conversion (สับสนหน่วยซ้ำ):** Caused by compounding unit conversion math twice.
* **5.3 Mistake Entry (คีย์ผิดจากค่าทำนาย):** If division fails, substitute with **Dynamic EWMA Forecast**. If the predicted value looks normal, classify as keying error.
* **5.4 Typo / Key-in Error (คีย์ลั่น):** If all hypotheses fail and the spike remains abnormal, flag as pure typo.

### 6. DUPLICATE IMPORT (บันทึกรับเข้าซ้ำ)
* **Hypothesis:** Duplicate data entry by staff.
* **Trigger:** Identical bill numbers or unnumbered imports with identical quantities on the same date.

### 7. BALANCE MISMATCH (ยอดคงเหลือไม่ตรง)
* **Hypothesis:** Retroactive bill editing, data drop, or upstream system errors.
* **Trigger:** Running Net Flow calculation from day one does not match system ending balance.
